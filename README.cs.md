# SunamoStorage

## Short description

Balíček SunamoStorage obsahuje třídy pro práci s úložištěm souborů a dat, např. ApplicationDataText, porovnávače názvů souborů s datem a DateTimeFileIndexT. Je součástí sady Sunamo, má testy i Runner a podporuje i polyfilly pro .NET Framework 4.8.
